## Anchor Text Strategy Overview

Anchor text is the visible, clickable text of a hyperlink. It is one of the most important signals for:
- Telling search engines what the linked page is about
- Building topical relevance and semantic context
- Avoiding over-optimization penalties (Penguin)
- Creating natural, editorial-quality link profiles

### Target Anchor Distribution (Internal Links)

| Anchor Type | Target % | Description |
|-------------|---------|-------------|
| Partial Match | 30% | Contains part of the target keyword |
| Branded | 20% | Brand name or product name |
| Exact Match | 15% | Exact target keyword phrase |
| Generic | 15% | "Click here", "Read more", "Learn more" |
| Contextual Descriptive | 10% | Descriptive of content, not exact keyword |
| Entity | 5% | Named entity (city, occasion, ingredient) |
| Question | 5% | Question-based anchor |

## Anchor Text Variation Rules

### For the Same Target Page, Vary the Anchor

For `/corporate-gifts/`, use these anchors across different pages:

1. "corporate gifts India" (exact — use sparingly)
2. "corporate gifting solutions" (partial)
3. "business gifting" (partial)
4. "corporate gift hampers" (partial)
5. "premium corporate gifts" (partial)
6. "Reet's corporate gifting" (branded)
7. "gifting for companies" (contextual)
8. "our corporate collection" (contextual)
9. "ideal for businesses" (contextual)
10. "get a corporate gift quote" (CTA)

**Rule:** No more than 20% of links to any single page should use identical anchor text.

## Anchor Text Anti-Patterns (Avoid)

| ❌ Bad Anchor | Why Bad | ✅ Better Alternative |
|--------------|---------|----------------------|
| "Click here" | No context | "Shop our corporate gift hampers" |
| "Read more" | Generic | "Read our Corporate Gifting Guide" |
| "Here" | Zero semantic value | "here in our FAQ" |
| "This page" | No entity signal | "our Dry Fruits collection" |
| Exact same anchor repeated 10+ times | Over-optimization | Vary with partial/branded anchors |
| Keyword stuffed anchor | Spammy | Natural phrase |
| URL as anchor | Poor UX | Descriptive text |

## Anchor Text for AI Search Optimization

AI search engines (Gemini, ChatGPT, Perplexity) prefer anchors that:
1. **Describe the destination precisely** — "Premium Cashew Gift Box" not "product"
2. **Include entity names** — "Diwali gifts" "Pune corporate gifting" "luxury hampers"
3. **Provide context clues** — "for more details, see our [Corporate Gifting Guide]"
4. **Use natural language** — "check our FAQ on shipping" not "SHIPPING FAQ CLICK HERE"
5. **Answer questions** — "learn how to choose corporate gifts" → links to guide

## Anchor Text Implementation SOP

### For Developers (Automated Links)
- Navigation links: Use short, exact or partial match anchors
- Breadcrumbs: Use exact page name as anchor
- Related products: Use product name as anchor
- Category links: Use category name as anchor

### For Content Writers (Contextual Links)
1. Write the sentence naturally first
2. Identify the keyword/phrase that best describes the destination
3. Make that phrase the anchor text
4. Check: Is this anchor unique from other anchors in this article pointing to the same URL?
5. Check: Is the surrounding context (50 words) descriptive of the linked page?

### For SEO Team (Auditing)
- Monthly: Run anchor text audit using Screaming Frog / Ahrefs
- Check: Ratio of anchor types (target: 30/20/15/15/10/5/5)
- Flag: Any URL with >25% exact match anchors
- Flag: Any URL with >40% generic anchors
- Fix: Update anchor text in content to diversify
