## Blog Linking Strategy Overview

Blog content serves as the topical authority builder that supports commercial pages. Every blog article must be a linking powerhouse that:
- Drives traffic to category and product pages
- Strengthens topical clusters
- Feeds AI knowledge graphs with entity context
- Creates pathways from informational to transactional intent

### Blog Linking Rule: MINIMUM 8 INTERNAL LINKS per article

| Link Type | Count | Target |
|-----------|-------|--------|
| Breadcrumb | 2 | Home + Blog Hub |
| Hub/Category | 1–2 | Parent topic hub |
| Product links | 2–4 | Relevant products |
| Related blogs | 2–3 | Sibling articles |
| FAQ link | 1 | Related FAQ page |
| CTA link | 1 | Contact or conversion page |

## Blog Linking SOP for Content Writers

### Before Writing:
1. Identify which topic cluster this article belongs to
2. List 3–5 products to mention naturally in the article
3. Identify 2–3 related blog articles to link to
4. Identify the relevant FAQ page
5. Identify the conversion CTA link

### While Writing:
1. Link to the hub/category page in the FIRST paragraph
2. Link to products naturally — not forced
3. Use descriptive anchor text — not "click here"
4. Link to related blogs in relevant sections
5. Include FAQ link near the end
6. End with CTA link to /contact/ or conversion page

### After Writing:
1. Count internal links (minimum 8)
2. Verify all links are correct URLs
3. Check no link anchor text repeats exactly (vary anchors)
4. Update related blog articles to link back to this new article

## Blog Internal Link Audit Triggers

Re-link existing blogs when:
- New product is added → Link from all relevant existing articles
- New category hub is created → Add link from all cluster articles
- New city page added → Add link from geographic articles
- New FAQ created → Add link from relevant articles
- Seasonal period approaching → Boost seasonal blog links from homepage and hubs
