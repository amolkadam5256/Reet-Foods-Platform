## Authority Flow Recommendations

### Authority Leak Points (Fix Immediately)
1. **Policy pages linked from header** → Move to footer only
2. **Blog pages with no outbound links to products** → Add 3–5 product links per article
3. **Product pages not linked from categories** → Add all products to category pages
4. **FAQ pages with no CTA links** → Add contact/quote links
5. **Orphan city pages** → Link from Corporate Hub + Footer

### Authority Concentration Points (Leverage)
1. **Homepage** → Ensure it links to all 10 Tier 2 hubs
2. **Corporate Gifts page** → Highest commercial intent; maximize inbound links
3. **Diwali Corporate Gifts** → Seasonal spike; create strong inbound chain
4. **Blog Hub** → Consolidates blog authority; must link to all articles

### PageRank Distribution Model

```
Homepage (100)
    40% → Corporate Gifts Hub
    15% → Dry Fruits Hub  
    10% → Gift Boxes Hub
    10% → Festive Gifts Hub
    8%  → Luxury Hampers Hub
    5%  → Wedding Gifts Hub
    5%  → Healthy Foods Hub
    4%  → Cold Pressed Juices Hub
    3%  → Blog Hub
    
Each Tier 2 Hub distributes:
    60% → Child product pages (equally divided)
    20% → Related Tier 2 pages
    10% → Supporting blog articles
    10% → Back to Homepage (breadcrumb)
```
