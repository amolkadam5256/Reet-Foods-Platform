## Category Page Linking Role

Category pages are the authority distribution engines of the website. They:
- Receive authority from Homepage and navigation
- Distribute authority to all child product pages
- Connect horizontally to related categories
- Anchor topic clusters as hub pages

### Category Linking Rule: MINIMUM 20 INTERNAL LINKS per category page

| Link Type | Count | Target |
|-----------|-------|--------|
| Navigation (auto) | Sitewide | Parent + siblings |
| Breadcrumb | 1 | Homepage |
| Sub-category links | 3–6 | Child sub-categories |
| Product links | 8–12 | All products in category |
| Related categories | 2–4 | Sibling categories |
| Blog articles | 2–3 | Supporting content |
| Buying guide | 1 | Category guide |
| FAQ | 1 | Category FAQ |
| CTA / conversion | 1–2 | Contact / quote |

## Category Page — Universal Linking Template (Developer)

```tsx
// CategoryPage component linking structure
<CategoryPage>
  <Breadcrumb items={[...]} />
  
  <CategoryHero>
    <h1>Category Title</h1>
    <p>Description with contextual links to related categories</p>
  </CategoryHero>

  <SubCategoryGrid links={subCategories} />  {/* 3–6 sub-categories */}

  <ProductGrid products={products} />  {/* All products in category */}

  <RelatedCategories categories={related} />  {/* 2–4 sibling categories */}

  <BlogSection articles={relatedBlogs} />  {/* 2–3 articles */}

  <FAQSection faqUrl={`/faq/${categorySlug}/`} />

  <CTASection 
    primaryCTA={{ text: "Get a Custom Quote", url: "/contact/" }}
    secondaryCTA={{ text: "Browse All Products", url: "/products/" }}
  />
</CategoryPage>
```
