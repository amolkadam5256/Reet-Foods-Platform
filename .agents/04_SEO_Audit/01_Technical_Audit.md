## 1.3 Sitemap

**Current (`app/sitemap.ts`):**
- 20 static URLs hardcoded
- Missing: all blog post slugs, all product slugs, all category slugs

| Check | Status | Finding |
|-------|--------|---------|
| Sitemap.xml exists | ✅ | Generated dynamically |
| All pages included | ❌ | Blog slugs missing |
| Product slugs included | ❌ | Only category-level URLs |
| Dynamic generation | ❌ | Static list — won't scale |
| lastmod dates | ❌ | Not present |
| Priority set | ✅ | Set per page |
| changeFrequency set | ✅ | Set per page |
| Image sitemap | ❌ | No image sitemap |

**Root Cause:** `sitemap.ts` uses a hardcoded `pages` array rather than fetching from a CMS or data source.

**Impact:** Blog posts and individual product pages are not guaranteed to be crawled or indexed.

**Priority:** HIGH

**Fix:**
```ts
// app/sitemap.ts — dynamic blog + product slugs
import { blogPosts } from "@/data/blog";
import { productCategories } from "@/data/products";

export default function sitemap(): MetadataRoute.Sitemap {
  const baseUrl = "https://reetfoodsngiftings.com";

  const blogUrls = blogPosts.map((post) => ({
    url: `${baseUrl}/blog/${post.slug}`,
    priority: 0.7,
    changeFrequency: "weekly" as const,
    lastModified: post.datePublished ? new Date(post.datePublished) : new Date(),
  }));

  const productUrls = productCategories.map((cat) => ({
    url: `${baseUrl}/products/${cat.slug}`,
    priority: 0.8,
    changeFrequency: "weekly" as const,
  }));

  return [...staticPages, ...blogUrls, ...productUrls];
}
```

## 1.5 Indexability

| Check | Status | Finding |
|-------|--------|---------|
| Homepage indexable | ⚠️ | `"use client"` — partial SSR concern |
| Products page indexable | ✅ | Server component with metadata |
| Blog page indexable | ✅ | Server component |
| Policy pages indexable | ✅ | Pass |
| No unintended noindex | ✅ | Pass |
| Noindex on private routes | N/A | No auth pages |

**Critical Issue — Homepage `"use client"`:**
- The homepage `app/(site)/page.tsx` is marked `"use client"` at line 1.
- This means the page renders in the browser, not on the server.
- Google will attempt to render JS but this creates a TTFB penalty and may cause empty initial HTML.
- **Fix:** Extract interactive components (hero slider, category accordion) to separate Client Components. Keep the page shell as a Server Component.

## 1.7 JavaScript Rendering

| Check | Status | Finding |
|-------|--------|---------|
| Homepage client-rendered | ❌ CRITICAL | `"use client"` entire page |
| (site)/layout.tsx client-rendered | ❌ | `"use client"` — nav, search, state |
| Products page | ✅ | Server component |
| Blog page | ✅ | Server component |
| Schema scripts | ⚠️ | Use `next/script` with `strategy="afterInteractive"` — schema is loaded late |

**Root Cause:** Schema JSON-LD is injected via `next/script` with `afterInteractive` strategy. For SEO schema, it should use `strategy="lazyOnload"` or better — render directly as `<script>` in SSR output using `dangerouslySetInnerHTML` inside the page component itself (not via `next/script`).

## Developer Instructions

### Fix 1 — Add HSTS + CSP headers
**File:** `next.config.ts`  
**Location:** `async headers()` function, global rule `source: "/(.*)"`.

```ts
{ key: "Strict-Transport-Security", value: "max-age=63072000; includeSubDomains; preload" },
{ key: "Content-Security-Policy", value: "upgrade-insecure-requests" },
{ key: "Permissions-Policy", value: "camera=(), microphone=(), geolocation=()" },
```

### Fix 2 — Add `/_next/` to robots disallow
**File:** `app/robots.ts`

```ts
disallow: ["/api/", "/assets/", "/_next/static/", "/_next/image/"],
```

### Fix 3 — Dynamic sitemap
**File:** `app/sitemap.ts`  
Import blog and product data, map slugs dynamically.

### Fix 4 — Remove `"use client"` from homepage
**File:** `app/(site)/page.tsx`  
Extract slider state into a `HeroSlider` client component. Keep `export default function Home()` as a Server Component.
