# Content-Keyword Mapping

## Overview

Master 1:1 mapping of all 899 keywords to their target URL, page type, template, CTA, and priority. This is the implementation bible — use it to assign keyword targets before creating any page.

> [!IMPORTANT]
> One keyword = One target URL. Avoid assigning the same URL to competing keywords (cannibalization).

---

## Cannibalization Prevention Rules

1. **One Primary Keyword Per URL** — Each page owns exactly one head term
2. **Supporting Keywords** — Up to 5 LSI / long-tail variants allowed per page
3. **Pagination Signal** — For paginated job listing pages, use `rel=canonical` to page 1
4. **Year Variants** — `sarkari naukri 2026` → Homepage; `sarkari naukri 2027` → Homepage (update annually)
5. **State + Department Combos** → Programmatic combination page, NOT state hub or dept hub
