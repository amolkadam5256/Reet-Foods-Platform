### People Also Ask (PAA) Capture

Use FAQPage schema on every informational guide:

```json
{
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "[keyword as question]",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "[150-300 word structured answer]"
      }
    }
  ]
}
```

### AI Overview (GEO) Optimization

Structure content to be cited in Gemini/ChatGPT answers:

1. **Lead with the direct answer** (first 2 sentences must answer the query)
2. **Use entity-rich language** — mention exam names, organizations, dates
3. **Add citation-worthy stats** — vacancy counts, salary ranges, eligibility ages
4. **HowTo schema** for step-by-step application guides
5. **Link to official sources** — UPSC, SSC, Railway board official sites
