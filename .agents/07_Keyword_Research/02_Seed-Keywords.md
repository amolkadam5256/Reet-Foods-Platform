# Seed Keywords

## Overview

Comprehensive list of seed keywords for SearchSarkariNaukri.com, forming the foundation of the keyword research strategy and organic search visibility.

## Purpose

To provide the foundational keywords that drive initial traffic and establish the platform's presence in government job searches across India.

## Research Goal

- Identify 899 core keywords spanning all job seeker needs
- Categorize by search intent, priority, and target audience
- Map each keyword to appropriate page templates and user personas
- Create a prioritized starting point for content development

## Data Sources

- SearchSarkariNaukri-Keyword-List-899.xlsx (Primary data source)
- Historical traffic data from Google Search Console
- User search queries and patterns
- Competitor keyword analysis

## Search Intent Analysis

| Intent Type | Example Keywords | Strategy |
|-------------|------------------|----------|
| Navigational | "sarkari naukri", "latest govt jobs 2026" | Optimize homepage and navigation |

| Transactional | "free job alert", "subscribe job notifications" | Convert with subscription forms |

## Best Practices

- Prioritize P0 keywords for immediate SEO focus
- Maintain consistent state-wise URL structure
- Create dedicated templates for each keyword category
- Monitor keyword performance in GA4 and adjust priorities
- Update keyword list quarterly based on performance data
