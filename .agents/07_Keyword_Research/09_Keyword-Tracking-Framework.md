# Keyword Tracking Framework

## Overview

Performance tracking system for all 899 keywords. Defines KPIs, GSC integration setup, monthly review cadence, and alert thresholds.

---

## Tracking KPIs by Priority

| KPI | P0 Target | P1 Target | P2 Target | Measurement Tool |
|-----|-----------|-----------|-----------|------------------|
| Average Position | Top 3 | Top 10 | Top 20 | Google Search Console |
| Click-Through Rate (CTR) | >5% | >3% | >1.5% | Google Search Console |
| Monthly Impressions Growth | +20% MoM | +15% MoM | +10% MoM | GSC + GA4 |
| Organic Sessions | +25% QoQ | +20% QoQ | +10% QoQ | GA4 |
| Featured Snippet Win Rate | 30% of P2 keywords | — | — | Manual GSC check |

---

## GSC Query Tracking Setup

### Step 1: Filter Setup in GSC
- Go to **Search Console → Performance → Search Results**
- Set **Date range:** Last 28 days (compare to previous period)
- Add **Query filter** → contains → keyword from priority list
- Export as CSV monthly for tracking

### Step 2: Keyword Grouping in GA4
- Create **Custom Dimensions** for keyword cluster tags
- Set up **Audience Segments** by landing page template type
- Configure **Conversions** for: Job Alert Subscribe, Apply Click, PDF Download

### Step 3: Monthly Export Checklist
- [ ] Export GSC Performance → Queries → Sort by Impressions
- [ ] Export GSC Performance → Pages → Sort by Clicks
- [ ] Export GA4 → Landing Pages → Filter by /state/, /department/, /jobs/ paths
- [ ] Compare to previous month baseline
