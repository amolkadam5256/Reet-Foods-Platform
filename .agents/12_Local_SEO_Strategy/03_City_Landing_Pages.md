## Technical Implementation

1. Create a `cities.csv` data file with all 100 rows.
2. Build a Next.js `[city]` dynamic route under `/app/corporate-gifts/[city]/page.tsx`.
3. Use `generateStaticParams()` to pre-render all 100 city pages at build time.
4. Inject LocalBusiness JSON-LD via `<LocalSchema>` component (see `16_Developer_Implementation.md`).
5. Add all city URLs to `/sitemap-cities.xml`.
6. Submit sitemap to Google Search Console and Bing Webmaster Tools.
