## Citation Submission Workflow (SOP)

### Step 1 — Prepare Assets
- [ ] Copy NAP table above to clipboard.
- [ ] Prepare 5 hi-res business photos (logo, store, products).
- [ ] Write a 200-word business description from 01_Google_Business_Profile.md.
- [ ] Prepare list of categories (Gift Shop, Corporate Gifts, Dry Fruits).

### Step 2 — Claim Existing Listings
- [ ] Search each directory for "Reet Foods" and "reetfoodsngiftings.com".
- [ ] If listing exists, claim and update with canonical NAP.
- [ ] If no listing, create new from scratch.

### Step 3 — Submit New Listings
- [ ] Fill all required fields using canonical NAP.
- [ ] Add description, categories, photos, working hours.
- [ ] Add website URL with UTM: `?utm_source=citation&utm_medium={directory}&utm_campaign=local`.
- [ ] Screenshot the submission confirmation.

### Step 4 — Verify Listings
- [ ] Complete email/phone verification for each directory.
- [ ] Log credentials in a password manager.
- [ ] Record the live listing URL in the Citation Tracker spreadsheet.

### Step 5 — Monitor & Audit (Monthly)
- [ ] Use BrightLocal or Whitespark to scan for citation inconsistencies.
- [ ] Correct any NAP variations within 48 hours.
- [ ] Add new directories monthly (target: 5 per month).
